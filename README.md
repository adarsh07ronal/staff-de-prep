# staff-de-prep

Single-page interview cheat sheet for the **Staff Design Evaluation Engineer** role
(Post-Silicon Engineering, Digital BU) at Analog Devices.

Open [`index.html`](index.html) in any browser — mobile-friendly, works offline,
collapsible sections, remembers which sections you left open.

## Contents

1. What post-silicon validation means in this role + the lifecycle
2. Worked example — new SoC bring-up, step by step
3. Concepts to have crisp (characterization, DFT, ADC/DAC metrics, high-speed compliance, instruments, automation, ADI products)
4. Positioning existing experience against the JD
5. Likely interview questions (technical + behavioral) and questions to ask them
6. Honest gaps and how to frame them
7. Night-before checklist

Personal prep material. Not affiliated with Analog Devices, Inc.
